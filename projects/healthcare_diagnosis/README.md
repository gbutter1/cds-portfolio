# Diagnosis & Flu Explorer

**Sector:** Healthcare (outpatient and emergency care)
**Question answered:** For a given facility, month and patient age group,
which diagnosis codes drive the most visits, what is rising, and how does the
facility's flu season compare with what the CDC saw across Georgia?

**Live app:** https://gbutter1.github.io/cds-portfolio/apps/diagnosis-explorer/

## Source data

Two sources, joined on the week:

1. **Facility encounters (synthetic).** Generated by `generate.py` from a
   fixed seed: six fictional facilities (an emergency department, urgent
   care, family practice, pediatrics, internal medicine and a community
   health center), October 2024 to September 2026, about 235,000 visits. Each
   facility type has its own diagnosis mix and age profile, and every code
   has its own seasonality (flu in winter, allergies in spring, injuries in
   summer). Diagnosis codes are real
   ICD-10-CM codes, described in the seed `dbt/seeds/icd10_reference.csv`.
2. **CDC ILINet, Georgia (real).** `fetch_cdc_flu.py` downloads the weekly
   share of outpatient visits for influenza-like illness reported by
   Georgia's ILINet providers, from CDC FluView via the public Delphi Epidata
   API. State-level weekly totals only. If the API is unreachable the
   pipeline still runs and the app marks the comparison as unavailable.

Deliberate defects in the encounter extract: codes without the dot or in
lower case (`j101`), codes that don't exist, missing codes, an unknown
facility, impossible dates, and duplicate rows. Format problems are repaired
and counted; everything else is rejected and reported in the app.

## Pipeline

1. `python projects/healthcare_diagnosis/generate.py` and `python projects/healthcare_diagnosis/fetch_cdc_flu.py` → `data/raw/healthcare_diagnosis/*.csv`
2. `python pipeline/load_raw.py healthcare_diagnosis` → `raw_healthcare_diagnosis.*` (all text)
3. `python pipeline/run_dbt.py build` → ICD-10 seed, `staging.stg_hc_*` views, `marts.hc_*` tables, tests
4. `python pipeline/export_app_data.py` → `evidence/static/apps/diagnosis-explorer/data.json`
5. Evidence build publishes the app alongside the other portfolio pages

## Model

| Table | Grain |
|---|---|
| `marts.hc_dim_facility` | facility |
| `marts.hc_fct_encounter` | visit (valid rows only) |
| `marts.hc_facility_month_dx` | facility × month × age group × diagnosis code |
| `marts.hc_facility_month_top10` | facility (and all facilities) × month × rank |
| `marts.hc_facility_week_flu` | facility × week, with flu share and alert flag |
| `marts.hc_cdc_ili_ga` | CDC epiweek (Georgia) |
| `marts.hc_data_quality` | dq_status |

A week is flagged as above baseline when the facility's flu share is more
than two standard deviations above its own off-season (June–September)
average, the same idea the CDC uses for its national ILI baseline.

## The app

A single static page (`evidence/static/apps/diagnosis-explorer/index.html`)
that reads the exported JSON in the browser, so it needs no server or
database connection. Pick a facility, month, age group and diagnosis
category, and optionally compare it side by side with another facility or with
all facilities combined.
